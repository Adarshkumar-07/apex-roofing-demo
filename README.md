# Apex Roofing — Portfolio Concept

A custom React/Vite website concept for a fictional Dallas roofing company.

## Visual direction
Cream, sandstone, terracotta/rust, sage green and muted sky blue. No black/dark-blue SaaS aesthetic.

## Run locally
npm install
npm run dev

## Build
npm run build

Apex Roofing is a fictional concept project. Contact details, testimonial and business information are placeholders for portfolio/demo use.
